# weijiba

这是一个无构建依赖的静态百科站，首页入口为 `index.html`，词条示例入口为 `article.html`，用于在 GitHub Pages 下直接访问。

页面模仿中文维基百科首页的侧栏、页签、内容模块和页脚层级，站点名称为“魏鸡百科”，副标题为“困困的百科全书”。内容根据 `鹿群` 文件夹中的聊天导出与分析报告二次编写，人物描述限定在群聊中可观察的称呼、表达和互动语境。

页面不连接真实百科后台；搜索、随机条目、外观、查看源代码、页面历史和编辑入口均为本地演示交互。

词条页采用目录、正文、外观三栏布局。右侧外观栏支持小/标准/大文本、标准/宽页面以及自动/浅色/深色三种颜色模式，并将设置保存在浏览器本地。

首页中的人物、群体、术语、科技方向、群史事件和热门标签都链接到 `article.html?entry=词条名`。`entry-data.js` 提供对应词条数据，并复用同一套词条页面结构和外观设置。

词条正文会按语义自动补充内部链接：每个章节首次出现的人物、群体、术语、工具或技术话题会连接到相应词条；当前词条不会自链，已有链接、按钮、标题和参考文献也不会被重复处理。

首页与词条页底部使用一个统一的 `WEIJIBA project` 项目标识，图像素材位于 `assets/weijiba-project.png`。

首页与词条页统一使用 `assets/wikipedia-logo-v2.svg.webp` 作为浏览器标签页图标；所有 `article.html?entry=...` 词条页面沿用同一设置。页面顶部的魏鸡百科品牌图仍使用 `assets/weijiba-logo.png`。

首页“更多群史”入口使用独立的 `article.html?entry=history` 群史词条，和“鹿群（微信群）”总览词条分开，便于按时间线继续浏览。
