# 罗宇伦 Roy Luo

个人网站：<https://roylyl.github.io/>

这是罗宇伦的个人作品集网站，用于集中展示工程经历、硬件与嵌入式项目、音频产品探索、产品与创业理念、音乐实践及联系方式。网站以原生 HTML、CSS 和 JavaScript 构建，可直接部署到 GitHub Pages。

## 当前内容

- **个人主页**：个人介绍、能力结构、精选项目、产品理念、音乐经历、社交媒体与联系入口
- **超声波定向扬声器**：ESP32、蓝牙音频接收、定向发声样机、硬件调试与工程验证
- **音享贴 LENGHE SoundShare**：多人蓝牙音频共享中继概念、产品结构、同步校准与多端 UI
- **产品与创业理念**：真实场景驱动、成熟技术组合、短期落地与长期技术投入
- **音乐实践**：DP 音乐工作室、Desk Park 乐队、电吉他与音频设备使用经验
- **独立页面**：KunCode 产品页面与“加密鹿”文字编码工具

## 设计与响应式体验

- 深色界面、玻璃质感、圆角卡片与统一的视觉层级
- 主页及三个主要二级页面支持简体中文、繁体中文和英文
- 桌面端与移动端分别适配导航、按钮、项目图片、内容密度和触控尺寸
- 移动端语言与背景音乐按钮采用统一圆形规格，桌面端采用统一胶囊按钮样式
- 主页移动端主要操作按钮等宽横向排列
- 项目图标和浏览器标签页图标采用与页面视觉一致的圆角或圆形资源
- 支持 `prefers-reduced-motion`，并为主要交互控件提供键盘焦点状态

## 页面导航与背景音乐

- 背景音乐默认静音，由访客主动开启
- 菜单栏提供“背景音乐静音 / 背景音乐打开”两种状态及对应图标
- 主页与二级页面之间使用同源嵌入式页面切换，背景音乐由主页统一管理，一级与二级页面往返时不中断
- 播放状态与进度保存在当前浏览器会话中；正常页面重载后会尝试从对应进度继续
- 当访客点击演出视频播放器时，若背景音乐已开启，背景音乐会自动静音
- 两个演出视频均不自动播放

背景音乐文件为 `assets/你离开了南京，从此没有人和我说话.mp3`。版权与非商业使用说明见本文末尾。

## 地区视频分流与访问提示

演出视频直接使用 YouTube 或哔哩哔哩的原生嵌入播放器，不使用自定义缩略图：

- 每次刷新主页都会重新检测当前 IP 所在国家或地区，不使用持久化地区缓存
- 中国大陆 IP 使用哔哩哔哩播放器；其他地区或检测失败时使用 YouTube
- 地区检测优先访问 `api.country.is`，失败时回退到 `ipapi.co`
- 中国大陆访问提示可复用首页当次检测结果；二级页面使用 `ipwho.is` 独立检测
- 访问提示的展示时间记录在浏览器本地，一小时内不重复弹出；该缓存不影响每次刷新时的视频平台检测
- YouTube 手机端使用更宽的内部渲染视口再等比缩放，使原生播放控件在窄屏上保持紧凑；全屏状态恢复正常比例

第三方播放器、地区接口及其数据处理规则由相应服务提供方决定。

## 本地存储

网站仅为界面偏好与连续体验使用浏览器存储：

- `roylyl.site.language`：语言选择
- `roylyl.background-music.v1`：当前会话中的背景音乐状态与进度
- `roylyl.region-notice.shown-at.v1`：中国大陆访问提示的一小时展示冷却时间

地区检测结果不会持久化保存。

## 本地查看

在项目根目录启动静态服务器：

```bash
python3 -m http.server 8000
```

随后访问 <http://localhost:8000/>。部分地区检测、第三方视频与跨页面功能需要通过 HTTP 页面测试，直接双击 HTML 文件可能受到浏览器安全策略限制。
