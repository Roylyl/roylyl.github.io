## 技术与体验

- **原生静态站点**：使用 HTML、CSS 和 JavaScript 构建，不依赖前端框架或构建工具，可直接部署到 GitHub Pages。
- **多语言界面**：主页及三个主要二级页面支持简体中文、繁體中文和 English，栏目、事实信息与简历入口保持同步。
- **响应式设计**：针对桌面端、中等宽度和移动端分别调整导航、内容密度、图片比例、按钮布局和触控尺寸。
- **连续浏览体验**：页面之间通过同源嵌入式切换保持导航与背景音乐状态，背景音乐默认静音，由访客主动开启。
- **视频地区适配**：主页根据访问地区选择 YouTube 或哔哩哔哩播放器；检测失败时使用 YouTube，视频不会自动播放。
- **可访问性细节**：支持键盘焦点、`Esc` 关闭菜单、点击菜单外部关闭、背景滚动锁定，以及 `prefers-reduced-motion` 动效减弱偏好。
- **轻量本地状态**：浏览器仅保存语言偏好、背景音乐会话状态和访问提示的展示时间；地区检测结果不会持久化保存。

## 本地查看

项目是无需构建的静态站点。在仓库根目录运行：

```bash
python3 -m http.server 8000
```

然后打开 <http://localhost:8000/>。

建议通过 HTTP 静态服务器访问，而不是直接双击 HTML 文件。地区检测、第三方视频播放器、跨页面通信和部分浏览器媒体策略在 `file://` 协议下可能无法正常工作。

## 发布

仓库可以直接作为 GitHub Pages 静态站点发布：

1. 在仓库设置中启用 GitHub Pages。
2. 将发布源指向包含 `index.html` 的根目录和目标分支。
3. 发布后访问 [https://roylyl.github.io/](https://roylyl.github.io/) 检查主页、项目页、语言切换、视频和移动端菜单。

站点没有构建步骤，也没有需要额外安装的运行时依赖。
