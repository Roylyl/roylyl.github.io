# Roy Luo · GitHub Profile Website

一个适用于 **GitHub Pages** 的暗色个人主页，定位为 **工程能力优先** 的个人作品集。

## 页面结构

- `index.html`：主页，展示个人定位、核心能力、项目概览、技能与音乐补充内容
- `ultrasonic.html`：超声波定向扬声器项目二级页面
- `soundshare.html`：音享贴 LENGHE SoundShare 项目二级页面

## 特性

- 深色调视觉风格
- 响应式布局，适配桌面端与手机端
- 滚动进度条与渐入动画
- 主页仅展示项目单图与概览，详情跳转二级页面
- 声享贴页面展示 iPad / iPhone / Android / 微信小程序 / Apple Watch UI
- 主页底部嵌入两个 YouTube 视频
- 可直接部署到 GitHub Pages

## 部署方法

1. 新建仓库，例如 `Roylyl.github.io`
2. 上传本项目全部文件到仓库根目录
3. 在 GitHub 仓库中打开 `Settings → Pages`
4. 选择 `Deploy from a branch`
5. 选择 `main` 分支和 `/ (root)`
6. 保存并等待部署完成

访问地址示例：

- `https://roylyl.github.io/`
- `https://roylyl.github.io/ultrasonic.html`
- `https://roylyl.github.io/soundshare.html`
