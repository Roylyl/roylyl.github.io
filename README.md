## 技术与体验

- **原生静态站点**：使用 HTML、CSS 和 JavaScript 构建，不依赖前端框架或构建工具，可直接部署到 GitHub Pages。
- **多语言界面**：主页及三个主要二级页面支持简体中文、繁體中文和 English，栏目、事实信息与简历入口保持同步。
- **响应式设计**：针对桌面端、中等宽度和移动端分别调整导航、内容密度、图片比例、按钮布局和触控尺寸。
- **粒子与玻璃效果**：主页和部分项目页使用 WebGL2 粒子背景，支持桌面鼠标交互；主页内容卡片共用玻璃样式。浏览器缺少所需 WebGL 能力或访客开启减少动态效果时，不启动粒子动效。
- **连续浏览体验**：页面之间通过同源嵌入式切换保持导航与背景音乐状态，背景音乐默认静音，由访客主动开启。
- **视频地区适配**：主页根据访问地区选择 YouTube 或哔哩哔哩播放器；检测失败时使用 YouTube，视频不会自动播放。
- **可访问性细节**：支持键盘焦点、`Esc` 关闭菜单、点击菜单外部关闭、背景滚动锁定，以及 `prefers-reduced-motion` 动效减弱偏好。

### 本地状态与外部服务

本站脚本使用 `localStorage` 保存语言偏好和访问提示的展示时间，使用 `sessionStorage` 保存背景音乐会话状态；地区检测结果不会持久化保存。

视频地区识别依次尝试 `api.country.is` 和 `ipapi.co`；访问提示优先复用该检测结果，在没有共享检测任务的页面使用 `ipwho.is`。识别为中国大陆时，主页切换到哔哩哔哩播放器；其他地区或检测失败时保留 YouTube。访问提示检测失败时不显示提示。

地区识别与嵌入视频需要连接第三方服务，其可用性取决于访问网络。本地状态说明仅针对本站脚本，不涵盖第三方播放器自身的存储行为。

## 本地查看

项目是无需构建的静态站点。在仓库根目录运行：

```bash
python3 -m http.server 8000
```

然后打开 <http://localhost:8000/>。

建议通过 HTTP 静态服务器访问，而不是直接双击 HTML 文件。地区检测、第三方视频播放器、跨页面通信和部分浏览器媒体策略在 `file://` 协议下可能无法正常工作。

| CSS / JavaScript | 修改资源后，更新引用页面中对应的 `?v=` 版本号；共用脚本需检查所有引用它的页面。 |
| 玻璃效果 | 主页卡片共用 `style.css` 中的 `.glass` 和 `--module-glass-*` 参数；同时核对移动端覆盖规则，避免给单个模块另设一套背景或模糊。 |
| 粒子背景 | 修改 [soundshare-particles.js](soundshare-particles.js)；`viewportMode` 区分全页背景与局部展示，密度、尺寸和交互参数应按使用场景检查。 |

玻璃卡片的入场动画应优先放在卡片自身。父容器长期设置 `will-change: opacity` 会创建背景采样边界，可能导致内部 `backdrop-filter` 无法模糊容器外的粒子，即使各卡片的模糊参数相同，显示效果也会不同。主页目前采用卡片级入场与 `will-change: transform`；调整时应实际滚动并截图对比能力、实习、项目等模块。

发布前检查：

- 三种语言的文字、日期和简历入口对应正确。
- 桌面、iPad 和 iPhone 宽度下没有横向溢出、内容遮挡或菜单错位。
- 模块玻璃效果一致，滚动入场与鼠标跟随粒子正常。
- 项目跳转、浏览器前进后退、背景音乐控制及视频播放正常。
- 执行 `git diff --check`，并在发布后重新验证线上资源已更新。

## 发布

仓库可以直接作为 GitHub Pages 静态站点发布：

1. 在仓库设置中启用 GitHub Pages。
2. 将发布源指向包含 `index.html` 的根目录和目标分支。
3. 发布后访问 [https://roylyl.github.io/](https://roylyl.github.io/) 检查主页、项目页、语言切换、三语履历下载、视频和移动端菜单。

站点无需安装 npm 依赖或执行构建；本地预览需要静态 HTTP 服务（上例使用 Python 3）。视频播放与地区识别依赖第三方网络服务。
