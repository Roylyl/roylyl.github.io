# 鹿传

纯前端、离线、无服务器的动态二维码文件传输工具。

## 使用方法

1. 两台设备都打开本网页。
2. 发送端：进入“发文件” → 选择单个文件 → 生成动态二维码。
3. 接收端：进入“收文件” → 启动摄像头 → 对准发送端二维码。
4. 所有分片收齐后会执行 CRC32 与 SHA-256 校验，通过后提供文件下载。

## 推荐启动方式

摄像头 API 通常要求安全上下文。推荐在电脑上运行：

- macOS：双击 `start-local-server.command`
- Windows：双击 `start-local-server.bat`

然后访问 `http://localhost:8080`。

## 浏览器要求

接收端当前使用浏览器原生 `BarcodeDetector` 识别 QR Code。推荐较新的 Chrome / Edge / Android Chromium 浏览器。不同 Safari/iOS 版本对该接口支持情况可能不同。

## 协议与校验

- QR 固定使用 Version 15-L，发送端完全离线生成。
- 文件可按 192/256/320 字节分片，默认单帧数据量为 256 字节。
- 每个数据帧带文件会话 ID、序号、总帧数和 CRC32。
- 元数据帧周期性重复，接收端可从传输中途加入。
- 元数据包含文件名、MIME、文件大小、总帧数、分片大小与完整文件 SHA-256。
- 接收完成后按序重组，并再次验证长度与 SHA-256。

## 说明

二维码传文件的吞吐量天然较低，适合小文件、配置数据、文本、证书、小图片等场景。大文件会产生大量帧，不适合与 Wi‑Fi / 蓝牙等高速链路竞争。
