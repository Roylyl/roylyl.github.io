KunCode 下载官网部署包

目录名：
kuncode

部署到 roylyl.github.io 仓库后，推荐结构：

roylyl.github.io/
└── kuncode/
    ├── index.html
    ├── style.css
    └── script.js

GitHub Desktop 操作：
1. 将整个 kuncode 文件夹复制到本地 roylyl.github.io 仓库根目录。
2. GitHub Desktop 中 Commit to main。
3. Push origin。
4. 保持 GitHub Pages 设置为 main / (root)。

访问地址：
https://roylyl.github.io/kuncode/

macOS Apple Silicon V1.0.0

说明：
- 网站会根据浏览器系统自动突出推荐 Windows 或 macOS 下载。
- 页面使用 KunCode 仓库中的水豚图标远程地址；若图片无法加载，会自动显示 K 作为后备标识。
