KunCode 下载官网部署包

目录名：
kuncode

部署到 roylyl.github.io 仓库后，推荐结构：

roylyl.github.io/
└── kuncode/
    ├── index.html
    ├── style.css
    └── script.js

GitHub Desktop 操作：
1. 将整个 kuncode 文件夹复制到本地 roylyl.github.io 仓库根目录。
2. GitHub Desktop 中 Commit to main。
3. Push origin。
4. 保持 GitHub Pages 设置为 main / (root)。

访问地址：
https://roylyl.github.io/kuncode/

发布新版本：
1. 在 index.html 顶部修改 kuncode-release 的 content。
2. 如果安装包命名规则不变，无需修改其他版本文字或链接。
3. 如果文件名变化，修改相邻的 kuncode-windows-asset 或 kuncode-macos-asset。

说明：
- 网站会根据浏览器系统自动突出推荐 Windows 或 macOS 下载。
- 页面使用本目录中的 apple-touch-icon.png 作为水豚图标，不依赖远程图片。
- 页面不依赖框架，可以直接部署到 GitHub Pages。
